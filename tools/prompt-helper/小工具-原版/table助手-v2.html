粘贴表格，一键导出

粘贴表格代码 / 内容，点击「解析」查看数据，支持 CSV / JSON 导出。

智能识别表头 data-field / th / 列索引 自动跳过 隐藏列与功能列 追加模式 分页粘贴按列合并
使用提示
  • ⚠️ 请确认当前内容包含全部目标数据；若表格为分页 / 虚拟滚动，请先切换「每页更多条」或滚动加载完成后再复制。
  • 自动识别 data-field / <th> / 列索引 作为列名，兼容字段变化。
  • 自动跳过隐藏列（display:none）与 复选 / 操作 类功能列。
  • 页面存在多个表格时默认解析第一个，可在「表格来源」中切换。
  • 开启「追加模式」后，再次解析将按列名对齐合并数据，适合分页粘贴场景。
  • 快捷键：Ctrl + Enter 快速解析。
