粘贴 URL，一键提取路径

每行一个 URL，自动循环解码并提取帆软文件路径，支持批量导出。

循环解码 最多 10 层，防死循环 帆软路径 提取 viewlet / reportlet 批量导出 CSV / 仅路径
使用提示
  • 每行一个 URL，支持批量；快捷键 Ctrl + Enter 快速解码。
  • 自动循环解码直到无 % 编码（最多 10 层，含定点保护，防止死循环）。
  • 自动提取 viewlet / reportlet 参数作为帆软文件路径，值若多层编码会二次解码。
  • 单条 URL 显示解码过程，多条显示结果表格并支持 CSV 导出。
  • 成功 = 提取到路径；失败 = 未识别到参数（解码结果仍会展示，便于人工核对）。
