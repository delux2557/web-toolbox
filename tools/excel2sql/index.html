使用提示

支持范围

  • 支持 .xlsx / .xlsm / .csv；不支持 .xls（老式二进制格式），请先另存为 .xlsx。
  • CSV 没有类型信息，默认整列按字符串输出；确认是纯数字列时可打开「CSV 自动推断数字」。
  • UNION ALL 超过 2000 行会明显变慢，建议改用「INSERT 分批」；超过 2 万行请改用数据库原生导入通道。

数据安全

  • 解析完全在浏览器里完成，文件不会上传到任何服务器。
  • 产物是纯文本脚本，但数据来自你的表格 —— 请勿对来源不明的文件直接在生产库执行。

使用要点

  • 表头行自动识别，判据与逐列明细在「详情」里；点预览中任意一行即可改判 —— 这是最容易出错的一步，建议扫一眼。
  • 选项一改就自动重新生成，无需点按钮。数据超过 5000 行时会切换为手动，点页签行的 ⋯ →「立即重新生成」出结果。
  • 按 Alt+Z 切换 SQL 是否折行显示（与 VS Code 同款键位），设置会被记住。
  • 列级类型统一：同一列只要出现过文本，整列就按字符串输出，避免 UNION ALL 的隐式转换报错。
  • 超长数字（超过 15 位）会保留为文本 —— 浏览器只有双精度浮点，转成数字会悄悄改写末尾几位。
