粘贴 URL，参数解析

每行一个 URL，自动解析结构、逐参数解码并识别类型，支持明细 / 宽表两种视图。

逐参数解码 独立多层，最多 10 层 类型识别 URL / JSON / 时间戳 / Base64 帆软高亮 viewlet / reportlet
使用提示
  • 每行一个 URL，支持批量；快捷键 Ctrl + Enter 快速分析。
  • 每个参数值独立循环解码（最多 10 层，含定点保护），层数见「层数」列；查询串中的 + 按空格处理。
  • 类型自动识别：嵌套 URL / 嵌套查询串 / JSON / 时间戳（换算可读时间）/ Base64 疑似。
  • viewlet / reportlet 参数高亮为帆软路径；重复参数名保留多行并标注「同名」。
  • 「参数宽表」视图：参数名取并集做列、每行一个 URL，便于横向对比与导出。
  • 本工具仅本地静态解析 URL，不发起任何网络请求。
